# Как редактировать контексты

Каждый `.md` — самостоятельная политика. Соня может менять понятные критерии и
примеры в тексте. Технические поля между `---` менять осторожно:

- `id` — постоянный уникальный ID;
- `version` — повышать при любом смысловом изменении;
- `direction` — `inbound`, `outbound` или `both`;
- `channels` — `web`, `api`, `ai`, `integration` или `*`;
- `priority` — чем больше число, тем раньше применяется политика;
- `mode` — `blocking` или `advisory`;
- `owner` — кто утверждает правило.

После изменения:

```bash
node scripts/build-context-bundle.mjs
node --test tests/*.test.mjs
```

Нельзя добавлять в контексты реальные данные пациентов, API-ключи или выдержки
из production-логов.
