# Исходящий API-контент

## Обязательные критерии

- Возвращаются только поля публичного контракта.
- Ошибка не раскрывает stack trace, SQL, внутренний путь, секрет или конфигурацию.
- Verdict, версия алгоритма и trace ID согласованы с сохранённым событием.
- Ответ не содержит данные другого пользователя.
- Текст результата соответствует фактически выполненному действию.

## Блокировать

- Утечку внутренних полей или credentials.
- Успешный статус при фактически невыполненном действии.
- Raw ответ внешнего AI без нормализации и schema validation.
