# Дополнительные agent-контексты

Файлы в этой папке созданы отдельно от сертификационных политик cBridge.
Сейчас здесь находятся роли контент-конвейера: исследователь, ТЗ-агент,
писатель, редактор и критик.

Они сохранены без изменений и намеренно не входят в
`generated/context-bundle.json`, потому что:

- часть файлов генерирует или редактирует контент, а не оценивает его;
- их frontmatter использует другой контракт;
- для них пока не определены direction, channel, owner и blocking/advisory mode;
- автоматическое включение генеративной инструкции в security policy изменило
  бы поведение незаметно.

Когда появится контентный маршрут, эти файлы можно подключить как отдельный
agent pipeline. `post-critic.md` можно адаптировать в advisory-политику только
после определения площадки, входного контракта и порогов решения.

## Размеченные источники

- [`aidadoc-serdce/`](aidadoc-serdce/) — книга «Мне к кардиологу» (2021):
  полный текстовый слой, смысловая расшифровка диагностических блок-схем
  и постраничное описание визуального содержания.

Книга является справочным архивным материалом и не входит в политики cBridge.
Ее медицинские рекомендации не считаются автоматически проверенными или
актуальными.
