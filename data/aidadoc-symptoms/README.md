# «Путеводитель по симптомам»: размеченная книга

Источник: `aidadoc_web.pdf`, 75 PDF-страниц, ООО «Айдадок», 2021.

Контрольная сумма исходника (SHA-256):
`c5fb9e18830064372481981746ff7aefcb1e765f08f64a5838c61e69ee849659`.

## Что находится в папке

- `source-transcript.md` — полный автоматически извлечённый текстовый слой,
  разделённый по PDF-страницам;
- `flowcharts.md` — каталог всех 49 схем, их входных формулировок и безопасных
  уточняющих вопросов для демонстрационного контура;
- `visual-guide.md` — описание структуры, цветов и диапазонов страниц;
- машинный каталог находится в `../../src/symptom-guide-data.js`.

Исходный PDF остаётся в предоставленном Соней каталоге Downloads. В web assets,
клиентский bundle и production он не копируется.

## Граница медицинской безопасности

Книга и её формулировки являются архивным материалом 2021 года. Разметка не
равна медицинскому ревью. Она не должна автоматически становиться клиническим
алгоритмом, диагнозом или назначением.

В демонстрационный runtime перенесены только:

- названия и охват 49 схем;
- словарь входных формулировок;
- безопасные уточняющие вопросы без дозировок и лекарственных назначений;
- общий экстренный стоп и консервативный маршрут к врачу.

Книжные заключения, лекарственные советы, пороги и полная топология стрелок
должны пройти отдельную смысловую расшифровку и медицинское утверждение перед
клиническим использованием.

## Как сверять материал

Для поиска слов используйте `source-transcript.md`. Для выбора схемы и
уточняющих вопросов используйте `flowcharts.md`. Любой спорный переход нужно
сверять с изображением соответствующей PDF-страницы: текстовый слой не хранит
направление стрелок.
